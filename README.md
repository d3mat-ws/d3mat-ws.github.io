# D<sup>3</sup>Mat26
Workshops in Computational Materials

This workshop introduces beginners to the fundamentals of Density Functional Theory (DFT), one of the most widely used computational methods for studying the electronic, structural, and optical properties of materials. Through lectures, tutorials, and hands-on sessions, participants will explore the basic principles of quantum mechanics underlying DFT, learn how to set up and perform simulations using modern DFT software, and gain practical experience in analyzing computational results. The workshop aims to build a strong conceptual foundation, promote the effective use of first-principles simulations in research, and encourage participants to apply DFT techniques to problems in materials science, physics, chemistry, and engineering.

Where
On-site and online event
PSG Institute of Advanced Studies, Coimbatore

Sessions Overview
This workshop includes interactive formats designed to foster discussions and collaboration:

Invited Talks: Discussions by experts on DFT fundamentals and applications.
Hands-on Sessions: Practical exercises for implementing and applying DFT simulations.
